## 2. 软文定位与场景策略

面向门店销售顾问/运营：把客户处境转成有依据、可预约验证的图文内容，推动一个明确动作。
每篇先确定一个主问题，再选择2–3个能回答该问题的事实；保留一个适用限制；不能把参数列表当故事。
写作链为：**场景判断 → 证据选择 → 平台结构 → 单一CTA**。场景判断附用户原话；产品能力句逐句指向事实，假设场景明确标注。

| 场景 | 切入问题 | 优先核实的证据（不是能力承诺） | 结构侧重与CTA候选，每篇只选一个 |
|---|---|---|---|
| 开学季 | 上课携带与课程软件怎么兼顾 | 精确型号重量、接口、软件适配条件 | 一天任务→取舍清单；提交课程软件清单 |
| 职场办公 | 提案/会议前在哪一步卡住 | 接口、投影/协同的设备与版本条件 | 会前→会中→会后；预约演示 |
| 内容创作 | 素材处理或提案哪项是硬门槛 | 屏幕版本、容量、软件/插件兼容限制 | 工作流→证据→待测项；提交必装软件清单 |
| 家庭换新 | 旧机资料与家人使用怎样接续 | 同型号易用性、迁移/服务的已记载条件 | 旧流程→迁移检查；咨询迁移步骤 |
| 企业采购 | 部署/外设/业务软件能否验收 | 对应SKU、服务适用范围、部署前提 | 需求门槛→验收表；提交采购需求 |
| 门店到访 | 哪一个亮点值得现场看 | 能现场验证的单个功能及步骤 | 问题→一个亮点→边界；预约到店 |
| 新品首发 | 变化对哪类任务有用 | 同库可比型号、版本、发布时间，动态价需重核 | 变化→适合/不适合；领取核验清单 |
| 节日营销 | 给谁买、主要做什么 | 对应型号使用条件与真实活动依据 | 对象→任务→选择条件；咨询需求 |

三型号入口继续保留`matebook-pro`、`matebook-14`、`matebook-pro-s`，不能按“Pro”模糊合并。
`Z/app/src/lib/content.ts:36–52`、`:57–72`、`:77–92`中的系统/芯片/重量等是待回查的基线记录，不是本规划新认证的事实。
