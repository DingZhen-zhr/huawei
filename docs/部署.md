# 部署说明（Supabase + Vercel）

## 1. Supabase（已完成）

| 项 | 值 |
|---|---|
| 组织 | 石头鸡白毛 |
| 项目 | huacai |
| Ref | `wetrxsiobiwyeavianvv` |
| 区域 | ap-southeast-1（新加坡） |

表结构见 `app/supabase/migrations/20261020000000_init.sql`：

- `sessions`：device_id（浏览器匿名 id）、slots、更新时间
- `messages`：会话消息（role / content / facts / options）
- `facts`：406 条型号事实与官方价格（由知识库导出）

重新灌数据：

```bash
cd app
node server/seed-facts.mjs
```

## 2. 环境变量（`app/.env`，不入库）

```
SUPABASE_DB_PASSWORD=...
SUPABASE_PROJECT_REF=wetrxsiobiwyeavianvv
SUPABASE_URL=https://wetrxsiobiwyeavianvv.supabase.co
SUPABASE_DB_URL=postgresql://postgres:...@db.wetrxsiobiwyeavianvv.supabase.co:5432/postgres
SUPABASE_POOLER_URL=postgresql://postgres.wetrxsiobiwyeavianvv:...@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres
DEEPSEEK_API_KEY=...
DEEPSEEK_MODEL=deepseek-chat
```

## 3. Vercel（待登录后执行）

```bash
cd app
npx vercel login          # 只需一次
npx vercel --prod
```

首次部署后，在 Vercel 项目设置里加环境变量：

- `DEEPSEEK_API_KEY`
- `DEEPSEEK_MODEL`
- `SUPABASE_POOLER_URL`（服务端连池，别用直连）
- `VERCEL=1`（自动注入，无需手填）

说明：

- `api/[...route].mjs` 复用 Express 应用，`server/index.mjs` 在 `VERCEL` 下不监听端口
- 部署环境没有知识库目录时，自动读 `server/fixtures/kb-facts.json`（95 KB 快照）
- 静态前端在 `dist/`

## 4. 本地继续跑

```bash
cd app
node server/index.mjs
npm run dev
```
