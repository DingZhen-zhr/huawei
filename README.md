# 华为 PC 营销软文 Agent

一个引擎，两个入口：内容运营（公众号 / 小红书）与门店导购（朋友圈 / 海报）。
输入产品、人群、场景、平台 → 查知识库 → 出四段式图文软文 → 事实核验 → 合规检查 → 可改可导出。

## 快速开始

```bash
node tools/build-kb.mjs "C:\\Users\\<你>\\OneDrive\\Desktop\\华为PC全板块深度知识库_v7"
node server.mjs
# http://127.0.0.1:5177
```

零依赖，Node 18+，不需要 `npm install`。

## 知识库导入

`tools/build-kb.mjs` 直接吃官方知识库包（目录或 zip），产出 `data/kb.index.json` + `data/media/`。

读取来源：

| 来源文件 | 用途 |
|---|---|
| `P1/00-全库横向索引/全型号参数联合矩阵.csv` | 型号清单 + 12 类结构化参数（主数据） |
| `P1/<线>/<型号>/图片索引.csv` + `images/` | 图片文件名、官网图注、来源页、建议用途 |
| `P1/<线>/<型号>/卖点与限制.md` | 一句话定位、表达边界、可用结论 |
| `P1/08-官方公开价格快照/官方价格快照.csv` | 金额、价格类型、条件、核验时间、官方 URL |
| `P6/02-平台模板/*.md` | 各平台写作指南（公众号 / 小红书 / 朋友圈 / 海报等 13 份） |

索引规模（v7 实测）：**10 个型号 · 53 张图 · 13 份平台指南 · 1522 个源文件**。

## 模型接入（BYOK）

右上角「模型设置」里填 Base URL、模型名、API Key，点「测试连接」即可切换。

- Key 保存在本机 `.config.json`（已 gitignore），页面只显示尾号 `sk-…abcd`
- 也可以走环境变量 `DEEPSEEK_API_KEY`，方便 CI 或临时覆盖
- 没配 Key 时自动回退规则写作，保证评委 clone 后不配任何东西也能跑
- 生成走 OpenAI 兼容接口，换供应商只改 Base URL + 模型名

系统提示词写在 [prompts/system.md](prompts/system.md)，按赛题手册要求的八个模块组织，可直接放进作品说明书。

## 目录

```
server.mjs            零依赖 HTTP：静态页 + /api/generate + /api/meta + /media
lib/pipeline.mjs      9 步流水线（场景解析→平台策略→检索→事实点→编排→生成→核验→合规→组装）
lib/rules.mjs         平台规则表 / 合规词表 / 事实核验 / 价格核验   ← 自研核心
lib/kb.mjs            知识库适配：读 data/kb.index.json，按场景给参数排序，带定位与边界
lib/kb-mock.mjs       占位数据（无索引时兜底）
lib/zip.mjs           最小 zip 读取器
tools/build-kb.mjs    知识库包 → 索引 CLI
public/index.html     任务台 + 四段式结果 + 换平台重跑 + 导出
test.mjs              6 条用例自测
```

## 仓库卫生

- `data/` 不入库：里面是知识库原文与图片，官方要求「不得对外传播资料」
- 任何 Key / Client ID / `.env` 不入库，截图与录屏不得出现完整凭证
- 合成样本 `test/fixture-kb` 可提交，保证 clone 后能跑通空转流程

## 已知问题

- 部分型号（如 MateBook 14 酷睿 Ultra）在价格快照里没有记录 → 文案不写价格，只写「以门店实时价为准」
- `MateBook X 系列` / `MateBook GT 系列` 是系列名，选型时应落到具体 SKU
- 图库 112 张，索引只收录重点型号目录下的 53 张；扩展产品图待补
