# huawei

华为｜浙客松小组协作公共库 · zxt 分支

## 当前工作台

基于原 React / TypeScript 工作台，按 [软文规划](docs/soft-article-plan.md) 实施四分区交付、九阶段过程详情。提供三型号独立入口、八场景策略、四平台规则、客户任务追问、修改重验、任务快照及同版本复制/下载。

**接入边界：当前实现自定义只读 ima 网关协议适配，尚未完成原生 ima API 与真实账号联调。** 指定知识库为“任德耀新建华为PC知识库”；没有有效网关或模型凭证时真实阻断，不使用静态模板冒充模型结果。本地 v7 不能作为已验证 ima 来源。

## 运行

```bash
cd app
npm install
npm run dev
```

打开终端显示的本机地址。缺配置也可以查看输入、四分区和真实阻断流程；正式格式导出保持禁用。需要接入时复制 `app/.env.example` 为 `app/.env.local`，只在服务端填写变量，详见 [网关合同与接入说明](app/server/README.md)。API 同时挂载到 Vite 开发与预览服务；仅上传 dist 到静态托管无法提供 API。

```bash
cd app
npm test
npm run build
```

测试使用明确标记的合成数据，不代表真实 ima 检索、模型文案质量或图片身份已验收。

## 交付和核验

- 四分区：场景判断、知识库依据、图文软文、核验结果；九阶段可展开查看。
- 检索资料必须保留原文、条目定位、日期、完整产品身份与条件；错型、冲突、无依据价格阻断。
- 模型输出为可追溯草稿。事实映射不是语义核验通过；人工逐句核对、图片加载及身份复核、平台规则满足后可导出人工复核格式。发布前仍需复核动态信息。
- 输入或修改要求变化会使旧核验失效。复制、下载均使用当前版本同一文本；草稿始终标记“不可发布”。
- 价格仅接受指定库 P1/08 同SKU当日复核记录，展示单价×数量、渠道、条件与出处。
