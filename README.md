# 门店增长智能体（zxt 分支）

浙客松·华为产业赛道（华为产业赛道）参赛项目：为华为 PC 门店销售顾问配备一个能独立干活的智能体——**懂客户 · 写内容 · 算准价 · 推到成交**。

## 目录

| 路径 | 说明 |
|---|---|
| `端到端演示样例.md` | 可直接演示的完整脚本：客户输入 → 追问 → 三栏清单 → 候选方案 → 报价单 → 小红书图文 → 演示方案 → 行动清单 |
| `系统提示词骨架.md` | 智能体系统提示词：检索顺序硬规则、报价五要素、拒答与转人工闸门、输出前检查 |
| `app/` | 可运行的 Web 原型（React + TypeScript + Vite + Tailwind + shadcn/ui），演示模式 + 自由对话 + 知识库证据回溯 |

## 运行原型

```bash
cd app
npm install
npm run dev
```

原型通过 Vite 的 `/@fs/` 机制读取本地「华为 PC 全板块深度知识库 v7」（需在 `app/vite.config.ts` 的 `server.fs.allow` 中配置知识库所在路径），因此每条结论都可展开查看知识库真实文件摘录。

## 设计要点（六大护栏）

1. 先追问后推荐：模糊需求不猜 SKU
2. 事实与表达分层：参数只从 P1 取，话术/软文从 P2/P6 取
3. 报价五要素 + 口径隔离：页面价/预估到手价/官网参考价/下架状态严格区分
4. 权限闸门：内部价、返点、项目特价自动转人工
5. 图片可回溯：文件名、来源、位置、图注齐全
6. 动态信息当日复核：旧快照标历史，不覆盖
