## 快速运行

> **前置**：知识库目录「华为PC全板块深度知识库_v7」需放在仓库根目录（与 `app/` 同级）。该目录体积较大，未纳入 git，请从共享盘获取。

### 1. 配置 API 密钥
```bash
cd app
cp .env.example .env   # 填入你的 DEEPSEEK_API_KEY（勿提交 .env）
```

### 2. 构建知识库向量索引（首次）
```bash
cd app
npm run vectorize      # 读取仓库内「华为PC全板块深度知识库_v7」，bge-m3 本地向量化
```

### 3. 启动服务端 + 前端
```bash
cd app
npm run server         # 终端 1：DeepSeek + RAG 服务端（端口 8787）
npm run dev            # 终端 2：前端（端口 3000，自动代理 /api）
```

- **软文工作台**：选产品（3 个易混淆型号）+ 场景（8 类）+ 平台（公众号/小红书/朋友圈/门店海报）→ 运行 9 阶段流水线 → 复制/下载四段式导出
- **自由对话（接入模型）**：由本地 bge-m3 向量检索 + DeepSeek 生成，现场可测混淆型号、无依据补贴、下架款、权限闸门；每次回复附「检索依据」
- **证据回溯**：每条结论下方展开「知识库证据」，实时读取知识库 v7 真实文件（需在 `app/vite.config.ts` 的 `fs.allow` 配置知识库路径）
- 应用内右上角「系统提示词」按钮可查看 8 模块提示词全文
