# 华采智营

华为 PC 门店内容生成与事实核验工具。销售选一个型号，补一句门店里真实发生的事，生成小红书、朋友圈、公众号、海报、视频号五个渠道的文案；价格、规格和承诺在发布前逐项核对。

主链路：

```
选今日选题 → 补一句门店细节 → 生成五渠道 → 确定性核验 → 改字 / 复制发布正文 / 打包导出
```

## 功能

- **今日任务台**：3 张有官方资料和产品图的选题卡，选一张就能写。
- **内容工作台**：一次生成 5 个渠道、11 个版本（小红书 3、朋友圈 3、视频号 3、公众号 1、海报 1）。
- **模型写作**：默认使用 DeepSeek；模型失败或超时会退回规则稿，界面会标出来，不冒充模型成稿。
- **事实账本**：10 个型号，价格分为官方商城价、参考价、冲突三种状态。冲突价和只有参考价的型号不写进内容。
- **发布前核验**：价格、规格、极限词、无依据承诺逐项检查；未通过的版本不能复制或导出，并给出原因。
- **少堆参数**：正文按平台限制数字密度，只留和顾客场景直接相关的一两个数字，其余放右侧资料栏。
- **配图**：官方产品图 + Canvas 排版，生成封面、事实卡、到店清单、海报和视频封面；可单张下载。
- **整包导出**：ZIP 里包含 `copy/`（仅通过核验的版本）、`images/`、`sources.json`、`manifest.json`。
- **顾客问答**：识别预算、用途、Windows/鸿蒙、否定表达和屏幕尺寸；结果可以一键转成内容任务。
- **门店与后台**：门店码登录、门店资料、价格冲突确认、候选事实和知识库导入（`/admin`）。

## 本地运行

需要 Node 20+。知识库目录 `华为PC全板块深度知识库_v7/` 放在仓库根目录，与 `app/` 同级。

```bash
cd app
npm install
cp .env.example .env
npm run server      # API，8787
npm run dev         # 前端，3000
```

打开 http://localhost:3000，点「进入演示门店」，或使用门店码 `HUAWEI-001` / PIN `246810`。

生产环境必须配置：

- `HC_SESSION_SECRET`：至少 32 字符
- `ADMIN_PASSCODE`：后台口令
- `DEEPSEEK_API_KEY`：不配也能跑规则稿，但模型生成不可用

数据库可以选 Supabase。`HC_PERSISTENCE=supabase` 时写 Postgres；不配或设为 `local` 时用本地 JSON，换机器会丢数据。

```bash
npm run db:migrate   # 首次使用 Supabase
```

## 生成与核验

| 条件 | 行为 |
|---|---|
| 有 `DEEPSEEK_API_KEY`，`HC_GENERATION` 不是 `rules` | 五渠道走模型 |
| 没有密钥，或 `HC_GENERATION=rules` | 全部用规则稿，界面显示来源 |
| 某个渠道失败或超时 | 只回退该渠道，任务记录 `fallbacks` |
| 模型写了没依据的数字 | 核验拦下；可尝试修复一次，仍不过就禁止发布 |

模型只负责表达，事实和价格由账本提供，核验代码有最终否决权。

## 知识库导入

只导入型号、图片索引和平台指南，不改事实账本，也不提交原始资料：

```bash
npm run kb:import -- ../华为PC全板块深度知识库_v7
# 或进 /admin → 知识库 → 从服务器知识库导入
```

默认读取仓库根的知识库，也可用 `KB_ROOT` 指定。导入写到 `app/server/data/kb/`（已 gitignore），当前为 10 个型号、53 张图、13 份平台指南。产品卡优先使用导入的官方主视觉图；模型写作会把对应平台的指南作为参考。

## 事实与合规

- 事实基准：华为官方公开页面快照，2026-10-17；价格只认官方商城页面价。
- MateBook 14 鸿蒙版价格冲突（5,899 / 6,599）冻结，管理员按 SKU 确认后才恢复。
- 只有官网参考起价的型号（例如已下架的 GT 14）标为参考价，不写进内容。
- 没有销售提供的真实细节，不生成内容。
- 只用官方产品图或门店实拍；AI 不生成产品外观，不画二维码；二维码未配置就留白。
- 演示门店、顾客和场景为虚构，产品事实与价格来自官方公开资料。

## 已知限制

- 配图已覆盖 8 个型号；MateBook D 14、D 16 没有干净的主视觉图，会提示「官方产品图未就位」，文案和导出不受影响。
- 知识库导入需要常驻服务器或本地环境；Vercel 这类只读文件系统不能执行导入。
- 部署到 Vercel 时函数最长 60 秒，五渠道默认内联生成；超时单渠道回退规则稿。见 `docs/部署.md`。
- 尚未接原生 ima OpenAPI，当前从 v7 本地快照读取事实与图片。
- 任务保存 30 天，暂无自动清理；Supabase Storage 未使用，二维码只支持外链。
- 暂无 PWA 和浏览器端到端测试。
