# AI+华为PC营销软文智能体（zxt 分支）

浙客松·华为产业赛道参赛项目：自研 Agent 完成 **理解需求 → 查找资料 → 选择图片 → 生成内容 → 核验结果** 的图文软文闭环。

## 目录

| 路径 | 说明 |
|---|---|
| `作品说明书.md` | **先读这个**：功能板块对照、系统提示词 8 模块、三组运行结果、复现步骤 |
| `系统提示词骨架.md` | 参赛系统提示词：角色与任务/场景理解/平台规则/知识库约束/图片规则/生成要求/核验规则/合规规则 |
| `端到端演示样例.md` | 门店导购场景端到端演示脚本（懂客户·算准价·写内容·推到成交） |
| `app/` | 可运行 Web 原型（React+TS+Vite+Tailwind+shadcn/ui）：9 阶段流水线工作台 + 自由对话抽查 |

## 快速运行

```bash
cd app
npm install
npm run dev
```

- **软文工作台**：选产品（3 个易混淆型号）+ 场景（8 类）+ 平台（公众号/小红书/朋友圈/门店海报）→ 运行 9 阶段流水线 → 复制/下载四段式导出
- **自由对话**：现场抽查混淆型号、无依据补贴、下架款、权限闸门
- **证据回溯**：每条结论下方展开「知识库证据」，读取已授权的资料文件（需在服务端 `KB_ROOT` 配置目录；公共部署不可挂载私有库）
- 应用内右上角「系统提示词」按钮可查看 8 模块提示词全文
