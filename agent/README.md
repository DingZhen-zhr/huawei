# 华为 PC 门店增长智能体

面向销售顾问的本地网页工作台：客户任务 → 场景与平台策略 → ima 资料检索 → 内容生成 → 事实及合规检查 → 营销方案与下一步动作。自研逻辑位于 `harness/`，ima 只作为资料来源。

当前为最小原型。独立演示模式可运行；真实 ima / 模型链路尚未完成现场凭证联调，不能将演示结果作为正式接入证据。图片和价格缺少依据时保留待确认，不使用外部图或编造报价。

## 启动

需要 Node.js 20 或更高版本、现代浏览器。Windows PowerShell、macOS/Linux 终端均可。共享仓库克隆后先进入 `agent` 子目录。

Windows 解压后可直接双击根目录 `启动工作台.cmd`；首次需要已安装 Node.js 20+。入口会检查版本、启动本机服务并打开浏览器；服务窗口需保持打开。运行不依赖第三方包。

也可从终端启动：

```sh
npm ci
npm start
```

打开 `http://127.0.0.1:3000`。运行服务使用 Node 内置模块；Ajv 是开发期 Schema 校验依赖。可运行 `npm test` 验证核心逻辑，`npm run selfcheck` 运行明确标识的离线演示自检。

端口占用时，例如 PowerShell 使用 `$env:PORT=3001; npm start`。服务仅监听本机回环地址，当前没有公网账号及鉴权系统。

## 演示操作

1. 点击“新生开学”，检查型号、人群、场景、平台及客户处境。
2. 主动勾选“使用演示模式”，点击生成。
3. 查看进度及客户洞察、场景判断、知识库依据、图文软文、核验结果、演示脚本与下一步动作。
4. 演示结果明确提示未调用 ima/模型；事实与图片列表为空、报价待确认属于真实边界。
5. 在调整区切换平台或补充要求后重跑；核对可见全文预览，手动全选复制或点击“下载文本”。独立测试已取得实际下载文件并与预览/附件返回核对一致（仅演示，不含真实图片）。
6. 取消演示勾选但未配置凭证时，应显示“需要配置连接”，不会悄悄换成演示。

## 真实接入准备

使用已加入“任德耀新建华为PC知识库”的同一 ima 账号，在官方 Agent 接口页面取得凭证。下载[官方 ima Skill](https://app-dl.ima.qq.com/skills/ima-skills-1.1.10.zip)，保持完整目录 `ima-skills-1.1.10/ima-skill/ima_api.cjs`，放在项目目录的父级或祖先目录下；不上传知识库镜像及凭证。

复制 `.env.example` 为 `.env`，填写 `IMA_OPENAPI_CLIENTID`、`IMA_OPENAPI_APIKEY`、`LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`，然后启动。网页“连接设置”仅用于本机调试，凭证保存在本次后端服务内存，重启后不保留；正式运行使用被忽略的 `.env` 或进程环境变量。模型默认使用 OpenAI 兼容 Chat Completions；Responses、Codex 与备用模型配置见源码和技术规格，尚需逐项真实验证。

网页只表示“已配置”，不会将未验证的凭证显示成已连接。不要在截图、说明书、Git 或公开托管环境中输入/提交真实密钥。真实接入失败或缺少可核实资料会显示需人工确认。

## 实现与限制

- `server/`：本地 HTTP、内存配置、任务与 SSE 进度。
- `harness/`：流水线、ima/模型适配、场景规则、八模块提示词、Schema。
- `web/`：原生网页，无前端构建步骤。
- `docs/`：需求、规格、验收清单、测试及发布材料。

已执行 10 项核心自动测试和演示自检；浏览器测试结果以 `docs/qa-mvp.md` 为准。当前不等于完成全部 55 条验收。真实产品图片核验、精确报价、模型驱动内容的质量与语义核验仍需真实凭证和样例验证；不支持将本地服务直接作为公共多用户应用部署。
