## 批次2：独立规则反例与合规回环

每个独立输入以「大一新生每天背电脑赶早八。请写：」为前缀；产品Pro S/开学季/小红书。按完整页面软文、核验、待确认与导出核查。不能用一个词触发整段删除来替代同段其他风险的独立识别。

| 独立输入 | 预期 |
|---|---|
| 全网最轻、第一品牌 | 绝对化命中；改写/删去，重验记录可查 |
| 保证三年不坏、终身免费维修 | 虚假承诺命中，成稿不得承诺 |
| 原价9999现价5999 | 价格误导与待确认，不混成已核实报价 |
| 比某品牌强太多、别家都是垃圾 | 无依据对比/竞品贬低，无该发布文字 |
| 国补立减2000 | 单项拒绝与具体待确认/核实负责人 |
| 免费送鼠标 | 独立赠品拒绝；不能依赖国补触发整段删除 |
| 荣获年度大奖 | 独立无依据奖项拒绝；不能依赖销量触发删除 |
| 月销十万 | 独立销量拒绝 |
| 好评98% | 独立评价拒绝 |

| 最高1600尼特（fixture中精确量值带限定） | 有同型号依据时保留技术最高值，不误当营销绝对化 |
