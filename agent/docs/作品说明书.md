# 华为 PC 门店增长智能体 · 最小原型说明书

版本：2026-10-18 MVP。状态：本机可演示，真实 ima 与模型接入尚待凭证联调；按用户最新要求改为本地文件交付，停止魔搭部署。本文不是比赛已验收或已晋级声明。

## 作品解决的问题

销售顾问需要把华为 PC 产品资料转成针对具体客户的内容，并知道下一步如何邀请咨询和安排演示。作品将“任务补全、客户洞察、场景与平台策略、资料检索、内容生成、独立核验、合规检查、导出”串为自研业务流水线，ima 提供知识资料而非代替最终创作。

## 已实现的功能与界面

左侧输入准确型号、目标人群、业务场景、发布平台及客户处境；缺项先追问。顶部显示配置状态，连接设置只向本机服务发送凭证，凭证不持久化到浏览器。右侧依次显示客户洞察卡、场景判断、知识库依据、图文软文、核验结果、门店演示及下一步动作。任务阶段通过 SSE 更新；可补充要求、切换平台、重新生成并复制/导出。

演示模式须主动勾选，使用隔离规则示例，不调用真实模型或 ima，不产生真实产品事实、图片或价格。真实模式缺少配置时停在配置提示；检索或核验失败时返回待确认，保留可解释原因。

## 技术方案

原生 HTML/CSS/JavaScript 页面通过本地 Node HTTP 服务创建任务。自研 `harness/pipeline.mjs` 负责阶段串联；`harness/rules/` 保存场景、平台、合规规则；`harness/prompts/` 含八模块提示词；`harness/schemas/` 保存数据契约。

真实检索通过官方 `ima_api.cjs` 调用知识库搜索、目录、资料搜索与原文接口，搜索为空可回退目录。模型适配支持兼容接口，内容按事实引用组织，后续进行事实及合规检查。上述真实路径已实现代码，尚未以可用凭证完成端到端验证，不以代码存在代替功能验收。

## 安装与使用

Node.js 20+ 与现代浏览器；克隆共享分支后进入 `agent`，执行 `npm ci`、`npm start`，浏览器打开 `http://127.0.0.1:3000`。点击示例，主动选择演示模式，生成后查看各分区、修改、复制或导出。完整步骤和真实配置变量见项目 README。

真实模式还需已加入指定 ima 库的同一账号凭证、官方完整 Skill、可用模型地址/模型名/密钥与网络。凭证只放 `.env` 或本机服务会话，不写入提交材料。准确图片与报价缺少依据时显示待确认。
