自研 Agent 流程

任务补全 → 客户洞察 → 场景与平台策略 → ima 资料检索 → 图文生成 → 事实核验 → 营销合规检查 → 导出。

Node.js 本地服务负责编排，业务规则、八模块提示词和 Schema 独立保存。ima 仅提供产品事实与图片，最终内容由自研业务流水线组织。

  • 输入型号、人群、场景、平台及客户处境，缺信息先追问。
  • 按场景调整切入与卖点，按平台调整结构与行动引导。
  • 六分区展示洞察、场景、依据、图文、核验及演示/下一步。
  • 修改后重跑完整核验，支持复制及文本导出；无依据图价待确认。

本机运行

Node.js 20+ 与现代浏览器，克隆共享分支 agent-dev 后进入 agent：

npm ci
npm start
# 浏览器打开 http://127.0.0.1:3000
npm test
npm run selfcheck

真实接入需同一 ima 账号的指定知识库读取凭证、官方 Skill、可用模型服务。凭证仅放 Git 忽略的 .env 或环境变量，不写进代码和截图。真实模式缺凭证会停止，不伪造连接。

限制与材料

真实图文检索与型号核验、报价算术、模型内容质量及完整平台适配仍待实测。本地服务无公共多用户隔离。报名提交入口由组委会另行通知。
